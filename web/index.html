  • Depuis QGIS (avec une configuration d'authentification Géoplateforme déjà connectée). Collez le script dans l'éditeur de la console Python (bouton « Afficher l'éditeur »), puis exécutez-le : il parcourt vos configurations d'authentification et affiche le jeton de chacune (« pas de jeton » pour celles qui n'en fournissent pas). Copiez celui de votre configuration Géoplateforme. 
    from qgis.core import QgsApplication
from qgis.PyQt.QtCore import QUrl
from qgis.PyQt.QtNetwork import QNetworkRequest
am = QgsApplication.authManager()
for cid, cfg in am.availableAuthMethodConfigs().items():
    r = QNetworkRequest(QUrl("https://data.geopf.fr/extraction/processes"))
    am.updateNetworkRequest(r, cid)
    h = bytes(r.rawHeader(b"Authorization")).decode()
    print(cfg.name(), "|", cid, "|", h or "(pas de jeton)")
    Si la session de la configuration a expiré, QGIS peut ouvrir une fenêtre de reconnexion : reconnectez-vous, puis relancez le script.
  • Depuis le Swagger officiel du service (swagger-ui) : bouton Authorize, puis le jeton apparaît dans la commande curl générée par Try it out.

Une connexion automatique (OAuth2) nécessite un client dédié enregistré côté Géoplateforme pour cette page : le client public du Swagger refuse toute redirection vers une autre origine.
