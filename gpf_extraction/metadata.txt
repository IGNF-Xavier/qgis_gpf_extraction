[general]
name=GPF Extraction
about=[EXPERIMENTAL / NOT FOR PRODUCTION] Extract IGN's BD TOPO® and other Géoplateforme products the authenticated user has access to, via the Géoplateforme's new extraction service, within a BBox or an administrative extent.
category=Vector
hasProcessingProvider=yes
description=[Plugin expérimental, en cours de calibration face au service réel] This tool allows you to extract the BD TOPO® and other products from the Géoplateforme's extraction service (OGC API - Processes), authenticated with your cartes.gouv.fr account. The extraction extent is either a BBox drawn on the map canvas or an administrative area (commune, département, région) searched by name. Fork of the original "BD TOPO® Extractor" plugin by Jules Grillot, rewritten around the new authenticated extraction service and renamed accordingly.

changelog=
    3.3.0 tables with no features at all in the requested extent are now removed from the downloaded GeoPackage automatically. The generation report (requested tables vs delivered layers, removed empty layers, download failures) is now also logged to the QGIS message panel, not just shown in a transient window, and no longer wrongly warns about a mismatch caused by the empty-layer removal itself. Major performance fix: the CSW metadata catalog (used to look up styles) was re-downloaded in full (~300 records) on every single extraction because its cache lived on a short-lived per-call client instance; now shared for the whole QGIS session — measured at ~35s blocking the UI on the first style lookup of a session (server-side catalog size, largely incompressible), near-instant on every one after that. Documented this CSW-based style-lookup mechanism and its cost as a known limitation, and the need for a dedicated SLD-discovery service tied to the extraction service itself.
    3.2.1 fixed a QGIS freeze with no recovery path: network calls had no timeout at all, so a stalled request (including an OAuth2 token refresh) could hang the whole UI thread indefinitely; now aborts after 30s (10min for downloads) with a clear error message. Fixed the "Aide" menu entry duplicating on every hot-reload. Fixed the map tool staying active after drawing a BBox (cursor stuck redrawing a rectangle on further clicks). download_all_results no longer loses already-downloaded files if one of several fails partway through. Added a small generation report (requested tables vs delivered layers, download failures) after a job completes. Clarified the "append" input's label ("Fusionner toutes les tables en un seul fichier") so its effect is clear without reading the API docs. Fixed a typo in one of IGN's published SLD file names that prevented automatic styling of the surface_hydrographique table. Fixed a false-positive style match ("piste_aerodrome" wrongly attributed to the "aerodrome" table instead of "piste_d_aerodrome").
    1.0.0 sphinx documentation, add metadata variable for schema, geometry column and crs.
    1.0.1 crs correction.
    1.0.2 crs correction for area calculation, adding a gif when export is loading
    1.1.0 add group by themes and style created by IGN.
    1.1.1 correct internet checker, add french translation, switch from Girhub to Framagit
    1.2.1 add style to saved layer, correct group insertion bug, correct minimize window when drawing an extent on linux, minor translation correction
    1.2.2 minor translation correction
    1.2.3 add rectangle tool improvement if the user click on end point as start point, add documentation
    1.3.1 make the plugin compliant with IGN's guidelines for géoplateforme integration
    2.0.0 add functionnality such as WFS format as a result, intersect within the selected layer, correct wfs max extent layer, improve ui with all those functionnality, qt6 compatible, documentation, code improvement and commenting
    2.0.1 minor qt6 correction, improve dialog activation for windows user
    2.0.2 add extraction logs in the final message box
    2.1.0 correct last bug for QGIS4, save style if layer is not added to the project, add deleteLater for QNetworkReply
    3.0.0 rewrite: replace the anonymous WFS flow with the new Géoplateforme extraction service (OGC API - Processes), add OAuth2 authentication (autonomous login or reuse of an existing QGIS authentication configuration), add administrative extent search, support any product the authenticated user has access to (not just BD TOPO). Experimental until validated against the live API.
    3.1.0 renamed to GPF Extraction (was "BD TOPO® Extractor"), fixed input parsing against the real API (title used as input id, "lifetime" retention field), added a table picker with automatic ST_Intersects spatial filters for VECTOR-DB extraction processes (BD TOPO, GPU_EXTRACTION...), aligned default values (GPKG format, append for multi-layer formats) with the official documentation. Still experimental.
    3.2.0 non-blocking, persistent job tracking across QGIS sessions ("Jobs en cours" menu: refresh status, download, open folder, forget, import jobs already known to the server); correct resolution of the extractData Atom feed (was previously downloading the wrong content due to server-side content negotiation and an HTTP cache quirk); automatic styling of extracted layers from styles referenced in the Géoplateforme's metadata catalog (CSW), with a picker when several styles match a layer, and a fix for a mislabelled character encoding in IGN's SLD files; various real-world fixes: don't send optional enum inputs unless set (was forcing 7z compression by default), prevent submitting without any table selected, disambiguate homonym communes with their département code, fix the results window not resizing to fit dynamic content, remove the map rubber band left behind after closing the dialog, replace a sublayer-loading API removed in recent QGIS versions, and a couple of PyQt6/QGIS 4 compatibility fixes.
